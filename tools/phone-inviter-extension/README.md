# 西班牙生活通 电话邀请助手

这是一个 Chrome / Edge 浏览器插件，用来在普通网页中识别西班牙电话号码。点击号码后，会打开 WhatsApp，并自动填好邀请对方访问西班牙生活通的文字。

重要说明：浏览器和 WhatsApp 不允许插件自动替你发送消息。插件只负责打开 WhatsApp 和填写内容，最后需要你自己点击发送。

## 安装方法

1. 打开 Chrome 或 Edge。
2. 地址栏输入 `chrome://extensions/` 或 `edge://extensions/`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本文件夹：`tools/phone-inviter-extension`。

## 使用方法

1. 打开任何普通网页。
2. 插件会自动识别西班牙电话号码，例如 `612 345 678`、`+34 612 345 678`。
3. 被识别的号码旁边会出现绿色“分享”标记。
4. 点击号码，会打开 WhatsApp，并填好邀请文字。
5. 检查内容后，手动点击发送。

## 修改邀请文字

点击浏览器右上角的插件图标，可以修改默认邀请文字，也可以临时关闭号码识别。
